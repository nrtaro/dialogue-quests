# AGENTS.md 改訂（2026-11-04 承認・適用済み）

2026-11-04 / Claude Code。詳細定義書 v1の§10-1と、レビュー指摘R1への対応。ユーザーの承認（「承認して画面接続」）を受けてAGENTS.mdへ適用した。開発用フラグの名前は ENABLE_PROTOTYPES=1。

## 変える理由

現行のAGENTS.mdは、初回デモの前提で書かれている。次の2点が、確定済みの10本収録と高い自由度（⑤くらい）に合わない。

1. 「初回の公開コンテンツは勇者の耳元のみ」：10本の試作を一覧へ登録できない。
2. 「前提・コスト・勝敗はコンテンツの純粋関数で決定」：有限の行動一覧を前提にした書き方で、自由な仕組みを状態へ登録する方式（作用案）が規約違反に見える。

「サーバーが正本、AIは提案のみ」「AIに成功を自己申告させない」は変えない。

## 改訂案

```diff
- - ゲームの正本はサーバー。AIは提案のみ。前提・コスト・勝敗はコンテンツの純粋関数で決定。
+ - ゲームの正本はサーバー。AIは提案のみ。AIの提案は「作用案」として受け取り、コンテンツの純粋関数が受理・条件付き・確認・不受理・無視を判定してから状態を更新する（docs/detailed-definition.md §2）。
+ - プレイヤーが作った新しい仕組みは、コンテンツが定義した可変状態への作用として登録できる。固定事実・鍵リスト・勝敗条件は変更できない。
  - 状態が変わる行動の描写は確定ルールから生成する。AIに成功を自己申告させない。
- - 初回の公開コンテンツは勇者の耳元のみ。テスト用定義は登録一覧へ追加しない。
+ - 一覧に登録するコンテンツは、ユーザーが承認したものに限る。試作中のコンテンツは開発用フラグの下でのみ表示し、テスト用定義は登録一覧へ追加しない。
```
