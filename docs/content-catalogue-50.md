# 独創的コンテンツ案50本

2026-11-03 / 比較・検討用。既存の「勇者の耳元」は50本に含めない。

後続ヒアリングで、既存「勇者の耳元」と01・07・13・19・25・30・31・37・48の計10種類を初期収録へ採用、44は初期収録から除外と決定。その他は拡張候補。以下の人物・条件・実装方法の細部はまだ仮案であり、新規コンテンツの実装は未着手。制約や実装方式は、高い自由度と内容別の終了方針に合わせて見直す。

関連： [方向性・モード・全体構成の提案](game-direction-proposal.md)。ジャンルの多さだけでなく、プレイヤーの中心的な行為が変わることを重視する。

難度のSは既存基盤を比較的使いやすい案、Mは状態・表示・判定の拡張が必要な案、Lは因果・複数の知識・画像など検証負荷が高い案。小規模な試作を想定した設計上の見立てであり、見積りや実測値ではない。文字版のない画像案を、現在の文字UIですでに動くとは扱わない。

各案は短編の検証を想定する。期限・ターン・資源の具体値はまだ未決で、公開時のルール表と試遊で調整する。成功/失敗の条件は採点と区別し、失敗でも人物の面白い講評へ到達できる案とする。採点役は世界に合う人物の候補であり、名前や口調の採用は未決。

## A. 関係・利害に介入する

### 01. 冷蔵庫の深夜国会

**題材・特徴：** 日常×小さな政治・調整

- **シチュエーション：** 停電前の冷蔵庫で、残り物たちが保存場所と翌日の献立を争っている。
- **プレイヤーが行うこと：** 食材の事情を聞き、配置・献立・譲歩を組み合わせた協定を提案する。
- **AIが担う役割：** 期限も誇りも異なる食材の代表を演じ、他の代表への約束にも反応する。
- **目的・成功・失敗：** 目的は廃棄を抑え、朝まで持つ共同方針を作る。 成功は保存容量内で、主要な食材の必須条件を満たす協定が成立する。 失敗は規定ターンで合意できない、または必須の保存条件を破る。
- **面白さの核心：** 昨日のカレーが古参議員として振る舞う一方、合意には現実的な配置が必要になる。
- **AIを使う必然性：** 自由な妥協案を複数の人格が異なる理由で評価し、交渉の連鎖を生む。
- **再挑戦で変わること：** 食材・残り時間・譲れない条件を入れ替える。
- **採点役の候補：** 冷凍室の元議長。プレイ記録を根拠に、当該課題に沿う項目を評価する。
- **実装上の見立て：** M / 文字 / 少人数の利害と容量は正本で管理。自由な協定を合意条件へ解釈する拡張が必要。

### 07. 鏡だけが目撃者

**題材・特徴：** ミステリー×視点・証言の再構成

- **シチュエーション：** 消えた展示品の最後の目撃者は、廊下の鏡。鏡は左右を逆に語り、映らない場所は知らない。
- **プレイヤーが行うこと：** 映った位置・順番・人物の特徴を聞き、視点を変換して現場を再構成する。
- **AIが担う役割：** 固定された事件記録から、鏡に見える範囲だけを自然な証言で返す。
- **目的・成功・失敗：** 目的は持ち去った相手と移動経路を証拠付きで特定する。 成功は人物・経路・根拠が事件の正本と一致する。 失敗は誤った人物を断定する、または規定ターン内に根拠を組み立てられない。
- **面白さの核心：** 嘘ではないのに、そのまま聞くと間違える証人との会話。
- **AIを使う必然性：** 定型質問だけでなく、任意の角度や比較の質問へ一貫した視点で答えられる。
- **再挑戦で変わること：** 人物・鏡の位置・死角・持ち去り方を替える。
- **採点役の候補：** 額縁の鑑識官。プレイ記録を根拠に、当該課題に沿う項目を評価する。
- **実装上の見立て：** S〜M / 文字 / 事件と見える事実は開始時に確定し、会話途中で真相を作り替えない。

- **AIを使う必然性：** 同じ記録を異なる質問で掘り下げ、端末の省略癖から真相を引き出せる。

- **採点役の候補：** 未来監査の留守電。プレイ記録を根拠に、当該課題に沿う項目を評価する。

- **実装上の見立て：** L / 文字＋法則カード / 反応の理由と変更可能な法則は先に開示し、未知の罰則を追加しない。

### 50. 留守中に世界を救っておいて

**題材・特徴：** 職業SF×委任・方針の実行試験

- **シチュエーション：** あなたは出張前の司令役。代理AIへ方針だけを残し、途中の報告を一度しか確認できない。
- **プレイヤーが行うこと：** 優先順位・禁止事項・例外時の相談基準をまとめ、中間報告を見て一度だけ修正する。
- **AIが担う役割：** 方針を受けて数段階の課題へ自律的に対応する代理と、事実を報告するGMを担う。
- **目的・成功・失敗：** 目的は直接操作できない時間も、代理が重要条件を守って連続課題を解けるようにする。 成功は必須の課題と保護条件を、委任した方針に基づく行動で満たす。 失敗は保護条件の重大違反、または課題を終えないまま委任期間が終了する。
- **面白さの核心：** 報告書が『だいたい救いました』で終わらないように、任せ方を考える。
- **AIを使う必然性：** 自然文の方針を状況が違う段階へ適用し、予想していなかった解釈を報告から学べる。
- **再挑戦で変わること：** 代理の性格・課題の順序・使える相談回数を変える。
- **採点役の候補：** 出張帰りの引継ぎ監査官。プレイ記録を根拠に、当該課題に沿う項目を評価する。
- **実装上の見立て：** M〜L / 文字 / 自動進行は固定の少数段階・ゲーム内操作だけに限定。外部サービスの自律操作は含めない。
