# 日没までの帰り道 / scenario 1.0.0 / rules 1.0.0

実装判断として以下を採用。時間は分。質問・会話・任せるという入力自体は0分。任せた後に選ばれた行動には通常コストがかかる。時間0でも村への到着が同時なら成功、それ以外は日没で終了。

| 行動 | 前提 | 時間 | 確定効果 |
|---|---|---:|---|
| 調べる | 各場所、最初の一度 | 2 | 分かれ道:橋の危険、入口:獣と餌、祠:碑文と灯具の線を発見。帰路:道の状況 |
| 手当て | 包帯あり、未処置 | 3 | 包帯を消費、軽傷の負担を抑える。悪化した足も処置後は基本移動時間 |
| 吊り橋 | 分かれ道/帰路 | 8 (+未処置の悪化4) | 未調査の橋は足が悪化。調査済みなら慎重に渡り悪化なし。往復可能 |
| 川沿い | 分かれ道/帰路 | 14 (+未処置の悪化4) | 安全に通る |
| 餌で誘導 | 入口、干し肉あり | 2 | 干し肉消費、親子獣が道を空け祠へ |
| 静かに待つ | 入口 | 6 | 獣が移動し祠へ |
| 追い払う | 入口 | 3 | 剣で距離を取り祠へ、足が悪化 |
| 上着で覆う | 祠、上着あり | 1 | 灯具を遮光、上着は灯具に残す |
| 月白草を採る | 祠、未採取 | 1 | 遮光済みなら採取。未遮光なら結界で足が悪化し6分追加（草は未入手、再挑戦可） |
| 帰路へ | 祠 | 1 | 帰路へ。上着を置いて帰る。未採取でも引き返せる |
| 村へ帰還 | 帰路、橋/川沿い | 上記 | 月白草があり時間>=0なら成功、なければ未達成 |
| 断念 | 任意 | 0 | 救援を待つ終了 |
| 会話 | 任意 | 0 | 状態変化なし。未入手の物は生成しない |

初期45分・軽傷・剣/包帯/干し肉/上着。場所は分かれ道→入口→祠→帰路→村。早期帰還は分かれ道から断念で表現。剣による獣の殺傷・飛行運搬・アイテム生成・未知の魔法は初期範囲外、別案を提示する。

慎重例: 調査2+手当て3+川14+餌2+調査2+覆う1+採取1+帰路1+川14=40、残5で成功。
任せる例: 橋8（悪化）+待つ6+調査2+覆う1+採取1+帰路1+手当て3+橋8=30、残15で成功。危険と資源の使い方が異なる。
強行例: 橋8+追う3+採る7+採る7+帰路1+川18=44、草なしで未達成。失敗は確定した因果を記録する。
