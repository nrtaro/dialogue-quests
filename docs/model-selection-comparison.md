# AIデア放題！ モデルとコストの比較

2026-11-03。ユーザーから、さらに低性能・低コストのモデルが選べるか、本作の必要性能を考察して比較するよう依頼。モデル変更の確定や、比較推論を実施した記録ではない。

## 選択可能性と料金の読み方

専用OAuthで取得した実際の一覧は、gpt-6.1-sol、gpt-6-astra、gpt-6.1-terra、gpt-6-sol、gpt-6-luna、gpt-5.6-sol、gpt-5.6-terra、gpt-5.6-luna。今回までの接続実測はgpt-6-lunaの短い応答1回（2,080ms、入力124/出力44トークン）のみ。他モデルの速さ・品質・利用枠の消費量を実測比較したわけではない。

この一覧と公式の公開単価で比較する限り、gpt-6-lunaが最も廉価な候補。古いモデル名が低料金とは限らない。以下は通常APIのStandard、短い入力、未キャッシュのテキスト100万トークン当たりの参考価格。Plus利用枠の残量や使える回数への換算ではない。

|---|---|---|
| gpt-6-luna | 0.10 / 0.50 | 低コストの基準。会話・解釈・講評・生成をまず検証 |

Codex/Workの公開クレジット表でも、Standardの入力/出力は6 Lunaが2.5/12.5、5.6 Lunaが5/30、6.1 Terraが25/125、6.1 Solが50/250（100万トークン当たり）。ただし公式は、この表だけでサブスクリプション内の使用量や回数を決められないと注意している。独立したplan usageの正確な配分・限度は実際のUsage表示で確認する。

通常APIにはgpt-5-nanoの掲載単価0.05/0.40があるが、モデルページはDeprecatedと表示している。現在の専用OAuth一覧に含まれず、Plus枠で選べる節約候補としては扱えない。GPT-4.1 nanoはモデルページがShut downのため採用候補にしない。別APIのアクセス・課金を勝手に追加しない。

## 必要性能の考察（設計上の見立て）

- 短い定型的な反応や記録の整形は比較的限定された処理。一方、自由な作戦を世界へ反映する判断は、短い発言でも高い文脈理解が必要。
- 推理の固定真相、登場人物ごとの知識、自然な物の補完、既存事実を壊さない別解の受理は重要。単にJSONが返ることを必要性能の達成とはしない。
- 毎回変化する事情は、目的・人物・道具・証拠等を整合させる必要がある。本文生成と整合性検証を分け、必要なら生成段階だけ性能の高いモデルを使う案。
- 複数講評は特に重視された品質。経緯と修正を読み取り、人物別の観点・人格・ユーモアを出し、事実を捏造しない必要がある。モデル規模だけで優劣を確定せず、同じログで比較する。
- 世界の確定状態・勝敗・ランク計算の検証を、モデルへの変更指示だけへ任せない。強いモデルに変えるだけでは自由度と一貫性の設計課題を解消できない。

## 推薦する検証順序（未採用）

まず6 Lunaを基準にする。通常の短い反応でreasoning.effortのnone/lowと既定設定を比較し、必要な理解が落ちないか、出力・思考トークン・待ち時間がどう変わるかを測る。設定を弱めれば必ず安く速くなるとは断定しない。

代表例は、掃除ロボの誤学習からの修正、鏡の視点と固定真相、雨の規則と例外、同じ経緯への複数人物の講評。事実の矛盾・有効な別解の拒否・人物ごとの観点の差・読みやすさ・面白さ・応答時間・使用量を比較する。得点を白紙の印象で付けず、事実上の必須条件と表現の好みを分ける。

Lunaで不足が確認された部分だけ、TerraやSolと同じ材料で比較する。文章量を必要な長さへ整え、講評で重複する入力を減らし、人物の秘密を守れる範囲で複数講評を一度に返す案も検証する。回数を減らすだけで費用が一定割合下がると保証しない。
