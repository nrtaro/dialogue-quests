# 素材の差し替え方

共通UIは特定の勇者や舞台を前提にしません。コンテンツの `info.visuals` が背景・人物・サムネイル・プレイヤーアイコンを指定します。指定しない枠は共通仮素材が使われます。仮素材は今回作成したオリジナルSVGで、参考画像の素材を流用していません。

## 1. 画像を置く

例として `public/assets/my-mission/` に画像を保存します。ファイル名は任意です。PNG・WebP・JPEG・SVGが使えます。キャラクターの立ち絵は背景透過PNG/WebPが適しています。

| 枠 | 推奨形状 | 表示方法 |
|---|---|---|
| thumbnail | 横長、例1280×800 | 一覧・概要で枠を覆うように表示。中央の人物や重要部分は端から離す |
| background | 縦横どちらも可、例1200×1600 | 人物ステージ全面に敷き、枠に合わせてトリミング |
| character | 縦長、例720×1040、透過推奨 | 立ち絵を全体が収まるように表示。会話中の小さな人物アイコンにも使用 |
| player | 正方形、例256×256 | プレイヤー紹介と会話アイコン。背景透過も可 |

仮ファイルを同じパスで上書きしても交換できますが、独自素材は `public/assets/` に置いて下記設定を変えると管理しやすくなります。

## 2. コンテンツの設定を変える

「勇者の耳元」は `src/content/hero-whisper/index.ts` の `info.visuals` です。

```ts
visuals: {
  thumbnail: { src: '/assets/my-mission/thumbnail.webp', alt: 'ミッションの内容が伝わる説明' },
  background: { src: '/assets/my-mission/background.webp', alt: '' },
  character: { src: '/assets/my-mission/partner.png', alt: '対話相手の姿', position: '50% 100%' },
  player: { src: '/assets/my-mission/player.png', alt: 'プレイヤーのアイコン' },
},
```

`public` はURLの先頭に含めません。`position` は任意のCSS object-positionで、既定は中央です。人物の足元を揃えるなら `50% 100%`。背景の注目部分を右寄りにするなら `70% 50%` などを指定します。装飾背景はaltを空にし、人物やサムネイルには内容を表す説明を付けてください。

一部の枠だけ指定しても構いません。共通仮素材のパスは `src/game/presentation.ts`。画像が読み込めない場合も、その枠の共通仮素材へ切り替わります。

## 3. 反映を確認

画像を同じファイル名で置換した場合は画面を再読み込み。コンテンツのTypeScript設定を変更した場合は `npm run dev` を起動し直し、新しいプレイを始めてください（既存セッションは開始時の設定を持つため）。

一覧・概要・プレイの3画面をPCとスマホで見て、意図せず顔が切れていないか、背景に文字が埋もれないかを確認します。画像ファイルの交換に会話・状態更新・API処理の変更は不要です。

## デザインの調整

共通の色と輪郭は `src/app/globals.css` 冒頭のCSS変数で調整します。`--ink`（輪郭と文字）、`--paper`（地色）、`--purple`、`--lilac`、`--mint`、`--coral`、`--yellow`。素材に文字やボタンを焼き込まず、UIはHTML/CSSのまま保つと、別コンテンツ・スマホでも使い回せます。
