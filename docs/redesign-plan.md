# コミック調UIへの刷新 / 2026-11-03

## 設計

依頼: 添付画像を手掛かりにコミカルで親しみやすい独自の外観へ刷新。背景/人物/サムネイルは仮素材で、後から交換可能。プレイでは会話のみスクロールし、それ以外は固定。全コンテンツ共通。

参考から抽出する原理は太い輪郭・大きな人物・吹き出し・明確な目的と操作。画面の配色、矩形配置、キャラクター、ロゴは複製しない。

比較した方向: 黄黒のゲームセンター風は参考に寄りすぎる。落ち着いた絵本風は今回のインパクト要求に弱い。実装判断として青紫/ミント/コーラル/クリームを使うコミックスタジオ風を採用。大きな角丸枠、少しずれた影、網点、手描き風の仮イラストと斜めの小ステッカーを組み合わせる。

PC: 画面上部にブランド/接続/目的、下は人物ステージ・会話・状況の3列。会話列は見出し/スクロール履歴/入力または結果の3段。人物・状況・入力を固定し、会話が増えてもbodyは伸びない。
スマホ: 上部にコンパクトな目的/主要状態、人物は横長の紹介バー、会話+入力を残り高さへ配置。詳細情報/ログ/リセットは下部固定。詳細は明示的に開くモーダルに収め、通常画面を押し広げない。100dvhとmin-height:0で短い画面も扱う。

素材: ContentInfo.visuals は任意。thumbnail/background/character/player をsrc/alt/positionで定義。未指定なら共通のオリジナルSVG仮画像。勇者固有の素材設定はそのコンテンツに閉じ込める。UIはタイトル・人物名・状態を定義から読む。

自動追従は会話コンテナのscrollTopだけを変更。過去ログを読んでいる間は追従を止め、新しい発言を送ると追従を再開。window.scrollIntoViewは使わない。visualViewportのheight/offsetTopを使い、キーボードで表示領域だけが縮む場合も入力欄をその中に固定。既存のAPI/正本/ログ/IME/障害再送は維持。
