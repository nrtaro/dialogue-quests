# ゲーム体験・表示・言葉の設計基準

2026-11-03 / ヒアリング中の作業資料。ユーザーの指定と、具体化のための提案を分ける。

## ユーザーが指定した方針

- コンテンツごとに難易度の幅を持たせ、星の数などで難しさを分かりやすく示す。
- デザイン、UI、言葉選び、コンテンツについて、親しみやすさ・分かりやすさ・独創性・インパクトを徹底する。
- コミカルな独自デザイン、交換可能な素材、会話部分だけがスクロールする共通UI。
- 自由な提案から、目的達成と意外な展開を楽しむ。項目別の評価と総合ランク、人物AIのユーモアある講評から再挑戦につなげる。
- 基本は1プレイ3〜5分で気軽に。コンテンツによってプレイ時間が変わってもよい。実時間の制限や一律の強制終了までは決まっていない。
- 達成・未達を明示しつつ、未達でも発想や過程によって高い総合ランクを狙えるようにする。配点と具体的なランク体系は未決。
- 初期から文字入力・音声入力の両方を用意する。最新の指定は端末・ブラウザーの音声認識を使い、認識した文字を確認・修正してから送る方式。以前の有料文字起こしAPI案は更新済み。対応端末・認識精度・開始停止等は未検証で、完全な端末内処理を保証する方式ではない。
- 終了は目的達成・状況上の続行不能・答えや作品の提出など、内容に合わせる。共通で「ここまでで採点」を選べる。基本3〜5分を過ぎただけでは強制終了せず、制限時間や回数は遊びに必要なコンテンツへ設ける。

## 具体化案：難しさを選ぶ前に分かる

追加回答で、低難度は低学年でも十分一人で遊べること、大人も発想次第で面白くなること、高難度でも状況は子どもが理解でき、難しいのはクリアの部分であることが指定された。全難度で入口を平易にし、条件の組合せ等で攻略の難しさを調整する。低難度でも工夫の広がりを残す。難しい言葉や長文を難度の代わりにしない。

対象は子どもから大人まで。状況的に不可能でない展開は指示によって可能にし、子どもの発想力と大人の知識を活かす高い自由度を目指す（ユーザー指定）。想定済みの解法以外も受け止める必要があり、現行の有限行動の解釈をそのまま完成仕様とはしない。

具体化案として、説明と基本操作は平易にし、専門知識がなくても試せる入口を用意する。採点は難しい言葉や文章量ではなく、その状況での工夫と効果を根拠にする。行動できることと必ず成功することは分け、反応と理由を伝える。これらの細則は定義書で検討する。

自由選択を中心とし、一覧から各自の興味で遊ぶ。リズム天国シリーズも、遊び方・親しみやすさ・独創性・インパクトの参考にする（ユーザー指定）。具体化として「することがすぐ分かる」「必要なら短いお試し」「行動の結果が表情や状況へ返る」を提案する。リズムや時間制限の導入は未決であり、この参照から自動的に採用しない。

- 一覧カードに「難しさ」と星を表示し、必要に応じて短い言葉を添える。例は「★★☆☆☆｜少しひと工夫」。5段階は提案で、最大数と名称はまだ決定していない。
- 読み上げ用に「難易度2、最大5」のような意味も付け、色だけへ依存しない。
- 難しさの星と、プレイ後の総合ランクは分ける。星を高評価の獲得数と誤解させない。
- 手掛かりの組合せ、同時に扱う条件、修正できる余裕などを各コンテンツで整理し、試遊で星の妥当性を調整する。
- 高いランクを目指す余地は、易しいコンテンツにも残す。すべてのコンテンツに難度選択版を作るとは、現時点で決めない。

## 具体化案：分かる言葉に、その世界らしい一言を添える

- 機能ボタンは「始める」「送信」「一覧へ戻る」など役割が分かる言葉を保ち、見出し・副題・吹き出し・講評で独自性を出す。
- 一覧には、題名だけでなく「何をして、何が変わるゲームか」を短く示す。例は「雨の許可ルールを作り、町の困り事を解決」。
- 評価項目もその課題に合う平易な言葉を使う。例は推理の「手掛かりのつなぎ方」、脚本の「話のつじつま」、育成の「教え方の伝わりやすさ」。これらの名称は提案で、配点や項目の採用は未決。
- 面白い採点文にも、今回の具体的な出来事と次に試せる工夫を残す。実人物の人格や会話能力の診断へ広げない。
- エラーや待機にも読みやすい表現を使うが、AI未接続や通信失敗などの実際の状態は隠さない。

## 具体化案：見た目だけでなく、遊びの違いで印象を残す

- 各コンテンツに、立場・意外な制約・自分の行為で変わる結果を一つの短い説明として用意する。
- 同じ質問回答の繰り返しにせず、推理、規則の設計、創作、教育などの違いを操作と結果へ反映する。
- 共通の外枠と読みやすさを保ちつつ、人物・背景・中心となる表示を差し替える。
- 装飾や動きで目的や入力を埋めない。固定UI、長文、スマホの表示領域、読み上げ、動きを抑える設定も確認する。
- 独創的な案でも、何をすればよいか、何が起きたか、なぜその評価かをプレイヤーが追えることを受入基準にする。
